## Project Overview
This project analyzes Major League Baseball hitting and pitching statistics using R. Completed as part of DAT 301 at Arizona State University, the analysis explores relationships between player positions, offensive performance, and pitching statistics.

## Technologies Used
- R
- ggplot2
- Plotly
- dplyr
- R Markdown

## Analysis
- Compared batting averages across defensive positions using boxplots.
- Examined the relationship between pitcher ERA and WHIP.
- Created an interactive 3D scatter plot comparing strikeouts, walks, and home runs allowed.
- Visualized home run totals and distributions across player positions.
- Conducted a two-sample t-test comparing batting averages of corner and middle infielders.

## Key Findings
- ERA and WHIP showed a positive relationship.
- Batting averages varied across defensive positions.
- The t-test found a statistically significant difference in batting averages between corner and middle infielders (p = 0.001973).
